## 📝 Problem-Solving Framework

### Before Starting a Problem:
1. Read problem carefully and identify:
   - Input/Output format
   - Constraints (size limits, special cases)
   - Key patterns (Two pointers? DP? Graph?)
2. Think of brute force first
3. Identify optimization opportunities
4. Code and test with examples
5. Check edge cases

### After Solving:
1. Analyze time/space complexity
2. Compare with other solutions
3. Document key insights
4. Practice variations

## 🎯 Meta Interview Tips

### Common Meta Question Patterns:
1. **System Design**: LRU Cache, Trie, etc.
2. **Array/String Manipulation**: Efficient traversal, in-place modifications
3. **Tree/Graph Problems**: BFS/DFS, path finding
4. **DP on Trees**: Combine recursion with memoization
5. **Bit Manipulation**: Optimization techniques
6. **Hard Backtracking**: Complex constraint satisfaction

### Interview Strategy:
- Always clarify requirements
- Walk through examples first
- Discuss complexity tradeoffs
- Code carefully to avoid bugs
- Test with edge cases
